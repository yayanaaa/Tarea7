RESUMEN HTML: PRINCIPALES CONCEPTOS Y ETIQUETAS

Esta pagina resumira los principales conceptos y etiquetas vistas en las clsases de Programación Web, en el modulo HTML

Conceptos principales HTML

HTML

Lenguaje de marcado de hipertexto es un lenguaje de marcas que se utiliza para estructurar citios Web

Elemento HTML

Un elemento HTML es la unidad basica de estructura y contenido en una página Web, y esta compuesta de:

  1. Etiqueta de apertura
  2. Pares atributos valor
  3. Contenido
  4. Etiqueta de cierre

Etiqueta <head>

Es una etiqueta que se utiliza para communicarse con el navegador a traves de los metadatos, permite mejorar el SEO, además se enlazan archivos externos de estilos o scripts

Etiqueta <body>

Dentro de esta etiqueta va todo el contenido que ve el usuario en nuestra página Web

Contenedores Semanticos

<header> Es una etiqueta utilizada para el contenido introductorio de una pagina web, puede contener el logo, el menu de navegacion, nombre de la empresa, etc
<nav> Etiqueta utilizada para el menu de navegacion principal, suele contener enlaces a otras paginas relacionadas o navegar por la pagina principal, no debe de haber mas en la pagina
<main> Etiqueta unica de una pagina web cuyo proposito es resaltar nuestro objetivo del sitio web, dentro se colocara el contenido principal de nuestra pagina
<section> Es una etiqueta que poco a poco se intenta que sustituya a <div>, su uso es para dividir una pagina web en secciones y agrupar contenido relacionado
<article> Es una etiqueta que se utliza para agrupar contenido autonomo, que si se separa de otro contenido sigue teniendo coherencia, normalmente se compone de un encabezado y contenido
<footer> Es una etiqueta que se encuentra hasta el final de una pagina y funciona como cierre del sitio web, a menudo contiene datos de contacto, derechos de autor u otra información complementaria
<aside> Esta etiqueta representa una seccion de la pagina web, cuyo contenido no esta directamente relacionado con el contenido principal del documento, como: barras laterales, publicidad, enlaces a otros articulos relacionados, etc

Elementos principales de HTML

Elemento<a>

Este elemento contiene enlaces para navegar a otras paginas:

  • Externos
  • Internos
  • Anclaje

Algunos valores especiales que tiene en su atributo href son:

href="https://wa.me/5637243929"
Este valor envia un whatsapp a un numero especificado
href="mailto:example@gmail.com"
Envia un correo a un mail especifico
